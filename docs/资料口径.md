# 资料口径

主体、设备和数值全部合成，不代表真实企业或实验结果。CSV 为 UTF-8，空值表示未知或不适用，不能当成零；布尔为 true/false。日期采用 ISO 格式，时刻带 +08:00 时区；日期区间左闭右开。金额为人民币元，概率为 0–1，除字段另有声明外数量为非负。CSV 排序不代表事件顺序。available_at 表示该事实最早可知时刻，历史截点不可使用较晚才知的值。样本用于开发，业务结论未预设。

一次告警的 event_id 标识独立现场疑点，多个报送可属于同一事件。assignment 是计划版本，resident 是实际版本；站内 group 共享班组。检查选择概率只适用于标为 random 的登记抽查，targeted 为定向核实；pending 的结果为空。need_action 指独立现场核实结果，不从告警代码推断。rollout 的 safety_increment 是风险增加上限，nuisance_reduction 是希望减少的比例，不是预定结论。回退时点后实际版本以驻留记录为准。
另有一条日界回退 RB1：它由 E17-2-0 的旧记录触发，在第18日00点开始占用2小时；第17日实际new，第18日起old，避免把同一组日误说为整日只有回退后版本。resident.run_hours已剔除停机；interventions引用触发组日，不保证发生在该组日内。

## code_map
版本专属告警语义。

记录键：['version', 'code']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| version | string | 固件 |
| code | string | 原代码 |
| family | string | 可比语义 |

## stations
站与班组能力。

记录键：['station_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| station_id | string | 站 |
| region | integer | 区域 |
| checks_daily | integer | 每日检查名额 |
| action_minutes_daily | integer | 处置分钟容量 |

## assignment
登记的组日安排。

记录键：['exposure_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| exposure_id | string | 组日 |
| station_id | string | 站 |
| group_id | integer | 组 |
| date | date | 日期 |
| assigned_version | string | 安排版本 |
| registered_at | datetime | 登记时点 |
| available_at | datetime | 可知时点 |

## resident
组日实际版本与暴露。

记录键：['exposure_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| exposure_id | string | 组日 |
| resident_version | string | 实际固件 |
| run_hours | number | 有效运行小时 |
| load_index | number | 负荷指数 |
| age_days | integer | 设备日龄 |
| available_at | datetime | 可知时点 |

## alarms
原始报送；同event重复不代表独立事件。

记录键：['message_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| message_id | string | 报送 |
| event_id | string | 现场疑点 |
| exposure_id | string | 组日 |
| code | string | 告警码 |
| occurred_at | datetime | 报送时点 |
| available_at | datetime | 可知时点 |

## verifications
现场核实含无告警抽查。

记录键：['check_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| check_id | string | 检查 |
| event_id | string | 疑点 |
| exposure_id | string | 组日 |
| selection | string | random或targeted |
| probability | number | 随机入选概率 |
| checked_at | datetime | 安排检查 |
| need_action | boolean | 核实需处置或未知 |
| delay_minutes | number | 处置延迟 |
| available_at | datetime | 结果可知时点 |

## interventions
严重事件后的处置。

记录键：['intervention_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| intervention_id | string | 处置 |
| exposure_id | string | 组日 |
| started_at | datetime | 开始 |
| kind | string | rollback或inspection_stop |
| hours | number | 干预时长 |
| available_at | datetime | 可知时点 |

## rollout_requests
扩围风险与容量需求。

记录键：['request_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| request_id | string | 申请 |
| station_id | string | 站 |
| units | integer | 拟扩围设备数 |
| safety_increment | number | 安全风险增加上限 |
| nuisance_reduction | number | 打扰减少目标 |
| cutoff | datetime | 观察截止 |
| review_by | date | 答复期限 |

## review_policy
事先登记查看与主要指标。

记录键：['policy_id', 'look_day']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| policy_id | string | 登记 |
| registered_at | datetime | 登记时刻 |
| look_day | date | 查看日期 |
| primary_metric | string | 主要指标 |
| scope | string | 站群范围 |
